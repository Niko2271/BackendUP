мини  backend  магазина одежды

Реализация REST API для магазина одежды на языке Go.

Стек технологий
Язык: Go
Роутер: chi
База данных: SQLite (драйвер modernc.org/sqlite)
Конфигурация: godotenv

Как запустить
1. Скопируйте файл `.env.example` в `.env`:
   cp .env.example .env
2. Запустите сервер из корня проекта
go run ./cmd/server

Реализованные сущности
Товары (Product) — CRUD, фильтрация, пагинация, сортировка.
Пользователи (User) — CRUD, поиск по роли.
Роли (Role) — CRUD.
Корзина (Cart) — добавление, просмотр, изменение количества, удаление.
Заказы (Order) — создание, просмотр, смена статуса (с валидацией).
Элементы заказа (OrderItem) — добавление, просмотр.
Фотографии (Photo) — добавление, просмотр, удаление.
